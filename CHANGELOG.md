# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-22

### Added
- Library: GPX parser, Tobler and steady-power cycling speed models, solar position and
  sunrise/sunset/civil twilight, route planning with latest start time and point of no return.
- Profiles: hike, trail, road, gravel, mtb.
- Command line tool `avant-la-nuit` with `--json` output and exit codes.
- Web app: drag-and-drop GPX, route and elevation profile coloured by daylight, point of no
  return marker, drinking water from OpenStreetMap, French and English, offline support.
- Tests against published sunrise/sunset times (Paris, San Francisco, Sydney, Tromsø).
